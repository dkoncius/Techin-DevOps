# 5 užduotis: Pull Request

Jei kas neveikia: perskaitykite klaidą, ieškokite dokumentacijoje ir užsirašykite, kas padėjo. Dirbtinio intelekto šiose užduotyse nenaudojame. Galite remtis ankstesnio dėstytojo pateikta Git komandų santrauka (`git komandos.pdf`, Teams'e). Užduotys eina viena gija ir visos vyksta jūsų `devops-projekte`. Atsakymus į „Kodėl“ rašote faile `docs/terminalas.md`.

**Tikslas:** Pateikti visą savo darbą per Pull Request ir sujungti jį į `main`.

**1 dalis: patikra ir siuntimas**

2. Patikrinkite, kad `docs` ir `scripts` nėra slaptažodžių, raktų, tokenų ar `.env` turinio.
3. Pažiūrėkite commit istoriją: turi būti keturi jūsų commit'ai.
4. Nusiųskite šaką `pamoka-02` į GitHub.

**2 dalis: Pull Request**

5. GitHub'e atidarykite Pull Request iš `pamoka-02` į `main` pavadinimu „Terminalas“.
6. Pull Request aprašyme (Description) vienu sakiniu parašykite, ką pakeitėte ir kodėl.
7. Peržiūrėkite Pull Request skirtumus (**Files changed**): turi matytis jūsų failai.
8. Sulieskite Pull Request GitHub'e.

**3 dalis: atnaujinimas ir tvarka**

9. Kompiuteryje persijunkite į `main` ir atnaujinkite jį iš GitHub.
10. Patikrinkite, kad `main` yra `scripts/ataskaita.sh`, `docs/ataskaita.txt` ir `docs/terminalas.md`, o commit istorijoje matyti visi commit'ai.
11. Ištrinkite šaką `pamoka-02` kompiuteryje.
12. Ištrinkite šaką `pamoka-02` GitHub'e.
