# 1 užduotis: Tęskite git-bandymas

1. **Tikslas:** tęsti 01 pamokos `git-bandymas` ir pradėti šaką `pamoka-02`.
2. Eikite į tą patį aplanką: `cd ~/Desktop/devops/git-bandymas`. `pwd` baigiasi `git-bandymas`. `ls` rodo `pastabos.txt` ir `idejos.txt`.
3. Atnaujinkite ir sukurkite šaką: `git switch main`, `git pull`, `git switch -c pamoka-02`. `git branch` rodo žvaigždutę prie `pamoka-02`.
4. Sukurkite failą: `nano uzrasai.md`. Įrašykite `# Terminalas`. Išsaugokite `Ctrl+O`, `Enter`, išeikite `Ctrl+X` (Mac'e Control, ne Cmd).
5. Išsaugokite Git: `git status` (`uzrasai.md` dar neįtrauktas), `git add uzrasai.md`, `git commit -m "Pradėtas uzrasai.md"`. `git log --oneline` viršuje ta žinutė.
6. **Pateikimas:** terminalo nuotrauka po `git branch`, kur žvaigždutė prie `pamoka-02`.

Jei užstrigote, pasižiūrėkite `linux komandos.pdf`. Git komandoms: [Git cheat sheet](https://git-scm.com/cheat-sheet).
