# Image ir registrai

- `docker pull nginx:1.27` → konkretus tag'as, ne `latest`
- `docker images` → TAG ir SIZE
- `docker history nginx:1.27` → sluoksniai
- `docker image rm alpine:3.20` → ištrinti nenaudojamą
- `docker login` → access token, ne slaptažodis. Šioje pamokoje neprivaloma
- `docker logout`
