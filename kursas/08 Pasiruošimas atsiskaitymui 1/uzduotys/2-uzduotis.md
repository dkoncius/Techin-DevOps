# 2 užduotis: Trys Pull Request

**1.** **Tikslas:** pamatyti, kad `git-bandymas` turi bent tris sulietus Pull Request.

**2.** Eiti į projektą ir pažiūrėti sulietus:

- `cd ~/Desktop/devops/git-bandymas`
- `gh pr list --state merged`
- Turi būti: sąraše yra pamokų 02, 03 ir 04 pavadinimai, bent trys

**3.** Jei trūksta, tą pamoką baikite: šaka, pakeitimas, Pull Request, Merge.

**4.** **Pateikimas:** `gh pr list --state merged` nuotrauka.

Git komandoms: [Git cheat sheet](https://git-scm.com/cheat-sheet).
