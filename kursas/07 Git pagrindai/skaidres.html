Užduotis

1 užduotis: Commit'ai ir diff

Peržiūrėti pakeitimus prieš commit ir padaryti du aiškius commit'us.

  1. Atnaujinkite main ir sukurkite šaką pamoka-07.
  2. Faile docs/git.md užrašykite vieną sakinį apie git diff, o faile README.md pridėkite vieną eilutę apie save.
  3. Pažiūrėkite pakeitimus prieš git add, pridėkite tik docs/git.md, pažiūrėkite, kas pridėta ir kas ne.
  4. Padarykite du commit'us (po vieną failą) su žinutėmis, kurios sako, ką pakeitėte ir kodėl.
  5. Peržiūrėkite paskutinio commit'o turinį.

Užduotis

2 užduotis: stash ir revert

Laikinai padėti pusiau padarytą darbą ir saugiai atšaukti pakeitimą.

  1. Papildykite docs/git.md ir nedarykite commit. Persijunkite į main taip, kad pakeitimas neprarastas, tada grįžkite ir atsiimkite darbą.
  2. Padarykite sąmoningai blogą commit'ą (pvz. ištrinkite visą docs/git.md turinį).
  3. Atšaukite jį nenaudodami git reset --hard, kad istorijoje matytųsi ir blogas, ir atšaukimo commit'as.
  4. Faile docs/git.md užrašykite, kuo git revert skiriasi nuo git reset --hard ir kada kuris tinka (pagal oficialią dokumentaciją; žingsnių čia nėra, tik tikslas).
  5. Padarykite commit.

Užduotis

3 užduotis: Konfliktas po pull

Susidurti su konfliktu, kai kita kopija pakeitė tą pačią eilutę, ir jį išspręsti.

  1. Nustatykite, kad git pull visada darytų sujungimą.
  2. Nusiųskite šaką pamoka-07 į GitHub ir sukurkite antrą savo devops-projektas kopiją ~/devops/devops-projektas-kopija (kitas aplankas, tas pats GitHub projektas), tada joje pereikite į šaką pamoka-07.
  3. Kopijoje pakeiskite docs/git.md pirmą eilutę, padarykite commit ir nusiųskite.
  4. Originale (devops-projektas) tą pačią eilutę pakeiskite kitaip ir padarykite commit.
  5. Originale paleiskite git pull: turi atsirasti konfliktas.
  6. Išspręskite konfliktą: paliekite vieną galutinį tekstą be žymeklių, užbaikite sujungimą ir nusiųskite.
  7. Ištrinkite kopijos aplanką.

Užduotis

4 užduotis: Grafikas ir Pull Request

Perskaityti istoriją ir sulieti darbą per Pull Request.

  1. Parodykite commit grafiką; turi matytis revert commit'as ir konflikto sujungimas.
  2. Atidarykite Pull Request iš pamoka-07 į main ir sulieskite. Kompiuteryje atnaujinkite main.
  3. Šaką pamoka-07 ištrinkite GitHub'e ir kompiuteryje.
  4. Patikrinkite, kad commit'e nėra slaptažodžių, raktų ar .env turinio.
  5. ⭐ Papildomai: pažaiskite [Learn Git Branching](https://learngitbranching.js.org/) skyrių „Remote“ ir užrašykite docs/git.md, ką sužinojote apie fetch.
