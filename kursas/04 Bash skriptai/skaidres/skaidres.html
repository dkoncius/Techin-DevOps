Komandos

if ir testai

bash
if [ "$#" -lt 1 ]; then
  echo "Naudojimas: $0 <vardas>" >&2
  exit 1
fi
  • Failui: -e, -f, -d; tekstui: =, -z; skaičiams: -eq, -gt, -lt
  • Ar komanda yra: command -v git

Komandos

for ir saugus skriptas

bash
for failas in docs/*.md; do
  echo "$failas"
done
  • set -euo pipefail: sustoja klaidoje, nenustatytame kintamajame ir nepavykusiame vamzdyje
  • Mac Bash 3.2: be ${var,,}, mapfile, declare -A

Užduotys

Užduotys

Užduotis skelbiu po vieną Teams'e: pirma parodau gyvai, tada darote jūs.

1 užduotis: Argumentas ir if

Parašyti skriptą, kuris tikrina vieną įrankį pagal argumentą ir grąžina išėjimo kodą.

2 užduotis: Ciklas per įrankius

Išplėsti tą patį skriptą, kad jis patikrintų įrankių sąrašą ir suskaičiuotų, kiek trūksta.

3 užduotis: Projekto failų patikra

Pridėti tam pačiam skriptui projekto failų patikrą ir suprasti [ ] ir [[ ]].

4 užduotis: run.sh, .gitignore ir Pull Request

Perskaityti tikrą Bash skriptą, patikrinti .gitignore ir pateikti visą darbą per Pull Request.

Pilnos užduotys su visais žingsniais bus įkeltos per Teams. Jei kas neveikia: perskaitykite klaidą ir ieškokite dokumentacijoje. Dirbtinio intelekto nenaudojame.
