10

Užduotis

1 užduotis: Issue ir geras PR

Susieti Issue su PR ir parašyti aiškų aprašą.

  1. Savo devops-projektas repozitorijoje GitHub'e sukurkite Issue „Papildyti README paleidimo skyriumi“ su 2–3 sakinių aprašu.
  2. Atnaujinkite main ir sukurkite šaką readme-paleidimas.
  3. README.md papildykite skyriumi „Mano pastabos“ su 3 punktais, kaip paleidžiate projektą savo kompiuteryje.
  4. Padarykite commit ir nusiųskite šaką.
  5. Atidarykite PR su aiškia antrašte ir aprašu (ką pakeitėte, kaip patikrinti) ir su nuoroda, kuri po sujungimo uždarys Issue. Dar nesulieskite.
11

Užduotis

2 užduotis: Peržiūra poroje

Peržiūrėti kito žmogaus PR ir atsakyti į savo.

  1. Pridėkite porininką prie savo repozitorijos kaip bendradarbį ir priimkite jo kvietimą.
  2. Raskite porininko PR (jo repozitorijoje) ir peržiūrėkite pakeitimus.
  3. Palikite vieną komentarą prie konkrečios eilutės ir vieną bendrą komentarą; paprašykite vieno pakeitimo (Request changes).
  4. Savo PR gavę komentarą atsakykite ir pataisykite (naujas commit į tą pačią šaką).
  5. Porininkas patvirtina jūsų PR (Approve), jūs jį sulieti. Patikrinkite, kad Issue užsidarė.
  6. Faile docs/review.md užrašykite: kokį komentarą gavote, kaip atsakėte ir ką išmokote peržiūrėdami kitą.
12

Užduotis

3 užduotis: Branch apsauga

Apsaugoti main ir patikrinti, kad apsauga veikia.

  1. Pagal oficialią GitHub dokumentaciją (Managing a branch protection rule) sukurkite savo devops-projektas šakai main taisyklę: prieš sujungimą reikalingas PR (žingsnių čia nėra, tik tikslas). Jei esate poroje ir turite antrą žmogų, pridėkite ir reikalavimą bent vienam patvirtinimui.
  2. Atnaujinkite main kompiuteryje, padarykite mažą pakeitimą ir bandykite git push tiesiai į main; užsirašykite atsakymą.
  3. Atšaukite vietinį pakeitimą (nenaudodami git reset --hard, jei jau padarytas commit'as, o ne tik pakeitimas).
  4. Padarykite tą patį pakeitimą per šaką ir PR ir sulieskite.
  5. Faile docs/review.md vienu sakiniu paaiškinkite, kodėl main verta apsaugoti.
  6. Papildomai: su gh išvardykite savo atvirus ir sulietus PR.
