Docker Desktop diegimas

Įdiegsite Docker Desktop Windows kompiuteryje, prijungsite jį prie Ubuntu (WSL) ir paleisite pirmą konteinerį. Komandas vykdysite PowerShell ir Ubuntu languose. Žymės išsaugomos tik šioje naršyklėje.

1. Pasiruošimas

Docker Desktop Windows sistemoje veikia per WSL 2. Jei WSL dar neįdiegtas, pirmiausia pereikite „WSL diegimo sąrašą“.

  1. Start meniu įveskite PowerShell ir atidarykite Windows PowerShell.

  2. wsl --list --verbose
    NAME STATE VERSION * Ubuntu Running 2

    Turi būti: eilutėje su Ubuntu stulpelyje VERSION yra 2.

    Jei rodo 1, žr. „Jei kas nors nepavyksta“.

  3. wsl --update

    Docker Desktop reikalauja naujos WSL versijos. Jei jau naujausia, komanda tai pasakys.

  4. Paspauskite Ctrl + Shift + Esc, atidarykite skirtuką Performance → CPU.

    Turi būti: apačioje prie Virtualization parašyta Enabled.

2. Docker Desktop įdiegimas

Diegimo programą atsisiųskite tik iš oficialios svetainės.

  1. Atidarykite docker.com/products/docker-desktop ir spauskite Download for Windows. Pasirinkite AMD64, nebent kompiuteris turi ARM procesorių.

  2. Dukart spustelėkite atsisiųstą failą. Jei Windows klausia leidimo, spauskite Yes.

  3. Lange Configuration turi būti pažymėta Use WSL 2 instead of Hyper-V (recommended). Spauskite Ok ir palaukite, kol diegimas baigsis.

  4. Kompiuteris persikraus. Neuždarykite lango be perkrovimo: be jo Docker nepasileis.

3. Pirmas paleidimas

Po perkrovimo Docker Desktop paleidžiamas pats. Jei ne, atidarykite jį iš Start meniu.

  1. Lange Docker Subscription Service Agreement spauskite Accept.

  2. Jei siūlo susikurti paskyrą ar prisijungti, spauskite Skip (arba Continue without signing in). Paskyros kursui nereikia.

  3. Turi būti: apatiniame kairiajame kampe ryškus žalias užrašas Engine running. Užduočių juostoje (šalia laikrodžio) matosi banginio ikona.

4. Prijungimas prie Ubuntu (WSL)

Kad docker komanda veiktų Ubuntu terminale, reikia įjungti integraciją.

  1. Viršuje dešinėje spauskite krumpliaračio ikoną Settings.

  2. Resources → WSL integration. Įjunkite Enable integration with my default WSL distro ir jungiklį prie Ubuntu. Spauskite Apply & restart.

    Jei WSL integration skiltyje Ubuntu nematyti, žr. „Jei kas nors nepavyksta“.

5. Patikrinimas

Atidarykite Ubuntu (Start meniu → Ubuntu). Paleiskite kiekvieną komandą ir palyginkite rezultatą su laukiamu.

  1. docker --version
    Docker version 28.1.1, build 4eba377

    Turi būti: eilutė, prasidedanti Docker version. Skaičiai gali skirtis.

  2. docker compose version
    Docker Compose version v2.35.1-desktop.1

    Turi būti: eilutė su Docker Compose version.

  3. docker run hello-world

    Pirmą kartą Docker atsisiunčia vaizdą (image), todėl užtruks kelias sekundes.

    Unable to find image 'hello-world:latest' locally ... Hello from Docker! This message shows that your installation appears to be working correctly.

    Turi būti: tekstas Hello from Docker!. Tai reiškia, kad Docker veikia.

  4. docker ps -a
    CONTAINER ID IMAGE COMMAND CREATED STATUS NAMES 3f2a1b9c8d7e hello-world "/hello" 10 seconds ago Exited (0) 9 seconds ago happy_name

    Turi būti: viena eilutė su vaizdu hello-world ir būsena Exited (0). Konteineris atliko darbą ir sustojo, tai normalu.

  5. Kairiajame meniu spauskite Containers.

    Turi būti: sąraše matosi tas pats hello-world konteineris su būsena Exited.

Jei kas nors nepavyksta

Docker Desktop nepasileidžia arba rašo, kad virtualizacija išjungta

Kompiuterio BIOS/UEFI nustatymuose išjungta virtualizacija. Perkraukite kompiuterį, įeikite į BIOS (paprastai F2, F10, Del arba Esc) ir įjunkite Intel Virtualization Technology arba SVM Mode (AMD). Mokyklos kompiuteryje BIOS gali būti užrakintas, tada kreipkitės į dėstytoją.

WSL needs updating / Docker Desktop requires a newer WSL kernel version

Atnaujinkite WSL PowerShell lange, tada paleiskite Docker Desktop iš naujo.

wsl --update
Ubuntu VERSION stulpelyje yra 1

Ubuntu veikia senesne WSL 1 versija. Perjunkite į WSL 2 ir palaukite, kol komanda baigs darbą.

wsl --set-version Ubuntu 2
The command 'docker' could not be found in this WSL 2 distro

Neįjungta Ubuntu integracija. Grįžkite į 4 etapą: Settings → Resources → WSL integration, įjunkite Ubuntu, spauskite Apply & restart. Tada uždarykite Ubuntu langą ir atidarykite iš naujo.

Cannot connect to the Docker daemon at unix:///var/run/docker.sock

Docker Desktop neveikia. Atidarykite jį iš Start meniu ir palaukite, kol apačioje pasirodys Engine running. Jei nepadeda, sustabdykite WSL ir bandykite dar kartą.

wsl --shutdown

Po to paleiskite Docker Desktop, palaukite žalio Engine running ir atidarykite Ubuntu iš naujo.

permission denied while trying to connect to the Docker daemon socket

Ubuntu viduje greičiausiai įdiegtas atskiras Docker per apt. Su Docker Desktop jo nereikia. Pašalinkite jį, tada uždarykite ir vėl atidarykite Ubuntu.

sudo apt remove docker.io -y
Ubuntu nėra WSL integration sąraše

Ubuntu turi būti įdiegtas ir bent kartą paleistas. Atidarykite Ubuntu iš Start meniu, tada Docker Desktop nustatymuose spauskite Refresh (arba perkraukite Docker Desktop).
