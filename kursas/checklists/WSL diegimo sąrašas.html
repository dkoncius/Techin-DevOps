WSL ir Ubuntu diegimas

WSL leidžia Windows viduje paleisti tikrą Linux sistemą. Atlikite žingsnius iš eilės ir pažymėkite kiekvieną atliktą. Žymės išsaugomos tik šioje naršyklėje.

0 / 0

1. Įdiegimas

  1. Paspauskite Win + R, įveskite winver ir paspauskite Enter. Reikia Windows 11 arba Windows 10 versijos 2004 ar naujesnės.

  2. wsl --install

    Jei rašo, kad reikia administratoriaus teisių, dešiniuoju pelės mygtuku spustelėkite PowerShell, pasirinkite Run as administrator ir paleiskite komandą dar kartą. Atsisiuntimas užtrunka kelias minutes.

  3. Kai kuriems kompiuteriams reikia perkrovimo, kad įsijungtų virtualizacijos funkcijos. Po to Ubuntu gali atsidaryti savaime.

2. Linux vartotojo sukūrimas

  1. Tik mažosios lotyniškos raidės, skaičiai ir brūkšneliai, be tarpų ir lietuviškų raidžių. Vardas neprivalo sutapti su jūsų Windows vardu.

  2. Rašant slaptažodį ekrane nieko nerodoma, net taškelių. Tai normalu. Įrašykite jį, paspauskite Enter ir įrašykite dar kartą. Jo prireiks kiekvieną kartą naudojant sudo, todėl užsirašykite.

  3. wsl -d Ubuntu

    Jei iškart po New password: matote PS C:\...>, slaptažodis neišsaugotas. Ši komanda vartotojo kūrimą pradeda iš naujo.

  4. Ubuntu klausia, ar galima siųsti anonimines naudojimo ataskaitas. Tinka ir y, ir n. Ubuntu veikimui tai neturi jokios įtakos.

  5. Turėtumėte matyti kažką panašaus į jusuvardas@PC:~$. Ženklas $ reiškia, kad esate Linux sistemoje.

3. Ubuntu atnaujinimas

  1. sudo apt update && sudo apt upgrade -y

    Paprašius įveskite savo Linux slaptažodį. Pirmą kartą tai gali užtrukti kelias minutes.

4. Patikrinkite, ar viskas veikia

Paleiskite kiekvieną komandą ir palyginkite rezultatą su laukiamu.

  1. wsl -l -v

    Turi būti: eilutė Ubuntu, kurios stulpelyje VERSION parašyta 2.

  2. whoami

    Turi būti: jūsų vartotojo vardas, ne root.

  3. sudo whoami

    Turi būti: root.

  4. cat /etc/os-release

    Turi būti: eilutė, panaši į PRETTY_NAME="Ubuntu 24.04 LTS".

  5. ls /mnt/c/Users

    Turi būti: sąraše matote savo Windows vartotojo aplanką. Jūsų C: diskas yra /mnt/c.

  6. curl -I https://ubuntu.com

    Turi būti: pirma eilutė prasideda HTTP/, o būsenos kodas yra, pvz., 200 arba 301.

  7. Įveskite exit, kad grįžtumėte į PowerShell, tada įveskite wsl, kad vėl atidarytumėte Ubuntu. Jūsų failai liks vietoje.

Jei kas nors nepavyksta

Klaida dėl virtualizacijos (0x80370102 ar panaši)

Kompiuterio BIOS/UEFI nustatymuose išjungta virtualizacija. Perkraukite kompiuterį, atidarykite BIOS (paleidimo metu dažniausiai F2, F10 arba Del), įjunkite Intel VT-x arba AMD-V / SVM, išsaugokite ir vėl paleiskite wsl --install. Jei nesate tikri, paklauskite mokytojo.

Pamiršau Linux slaptažodį

PowerShell lange atidarykite Ubuntu kaip root:

wsl -d Ubuntu -u root

Tada nustatykite naują slaptažodį (vietoj jusuvardas įrašykite savo vartotojo vardą) ir įveskite exit:

passwd jusuvardas
Eilutėje rašo root@... vietoj mano vardo

Vartotojas nebuvo sukurtas. Būdami root, paleiskite šias komandas su savo vartotojo vardu:

adduser jusuvardas
usermod -aG sudo jusuvardas
printf "[user]\ndefault=jusuvardas\n" >> /etc/wsl.conf

Tada įveskite exit, PowerShell lange paleiskite wsl --terminate Ubuntu ir vėl atidarykite wsl.

wsl -l -v rodo VERSION 1

PowerShell lange pakeiskite į WSL 2:

wsl --set-version Ubuntu 2
Kažkas užstrigo arba veikia keistai

PowerShell lange visiškai išjunkite WSL ir vėl atidarykite wsl. Jūsų failai išliks.

wsl --shutdown
