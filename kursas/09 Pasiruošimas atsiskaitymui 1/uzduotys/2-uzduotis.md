# 2 užduotis: Trys Pull Request

1. **Tikslas:** pamatyti, kad `git-bandymas` turi bent tris sulietus Pull Request.
2. `cd ~/Desktop/devops/git-bandymas`.
3. `gh pr list --state merged`. Sąraše yra pamokų 02, 03, 04 ir 05 pavadinimai. Turi būti bent trys.
4. Jei trūksta, tą pamoką baikite: šaka, pakeitimas, Pull Request, Merge.
5. **Pateikimas:** `gh pr list --state merged` nuotrauka.

Git komandoms: [Git cheat sheet](https://git-scm.com/cheat-sheet).
